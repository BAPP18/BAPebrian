🔑 Password Strength Checker + Generator

Cek kekuatan password (entropy, pola umum) atau generate password aman. Port web dari password_tool.py.

📜 Log Analyzer

Tempel isi log (SSH auth atau web access log). Deteksi brute force SSH & directory scanning. Port web dari log_analyzer.py.

🎣 Phishing URL Detector

Analisis heuristik URL: IP sebagai domain, shortener, kata mencurigakan, redirect trick. Port web dari phishing_detector.py.

🌐 Port Scanner

Port web (demo edukatif) dari port_scanner.py. Browser tidak bisa melakukan TCP connect langsung, jadi hasil scan di sini adalah simulasi berdasarkan hostname.

⚠️ CVE Scanner (NVD API)

Cari CVE terkait software/versi via NVD REST API. Port web dari vuln_scanner.py. Contoh: apache 2.4.49 atau openssl 1.0.1.

📡 Network Packet Sniffer — Panduan

Tool packet_sniffer.py menangkap traffic jaringan secara real-time (TCP/UDP) menggunakan Scapy. Ini butuh akses socket raw + hak admin — tidak bisa dijalankan di browser. Berikut cara kerja & cara menjalankannya.

Kebutuhan: Python 3, Scapy, dan root/admin (untuk raw socket).
Instalasi: pip install scapy
Jalankan: sudo python main.py → pilih menu 6 (Network Packet Sniffer)

Cara kerja

  1. Program memilih interface network (kosongkan = interface default).
  2. Scapy melakukan sniff() — menangkap paket raw dari interface.
  3. Setiap paket dicek: apakah mengandung lapisan IP, lalu apakah TCP/UDP.
  4. Untuk setiap paket TCP/UDP dicetak [TCP] src:port → dst:port atau [UDP] ...
  5. Default menangkap 20 paket (bisa diubah di menu).
⚠️ Sniffing tanpa izin atas jaringan orang lain adalah ilegal. Gunakan hanya pada jaringan milik Anda / lab Anda.
💡 Karena keterbatasan browser, port ini menampilkan panduan & tidak menjalankan sniffing langsung.
