Network Packet Sniffer — Guide

The packet_sniffer.py tool captures live network traffic (TCP/UDP) with Scapy. That needs raw socket access + admin rights — impossible inside a browser. How it works and how to run it:

Requirements: Python 3, Scapy, and root/admin (for raw sockets).
Install: pip install scapy
Run: sudo python main.py → menu 6 (Network Packet Sniffer)

How it works

  1. The program picks a network interface (blank = default).
  2. Scapy calls sniff() — capturing raw packets from the interface.
  3. Each packet is checked for an IP layer, then TCP/UDP.
  4. Every TCP/UDP packet prints [TCP] src:port → dst:port or [UDP] ...
  5. Captures 20 packets by default (configurable in the menu).
Sniffing networks you are not authorized for is illegal. Only use it on your own networks / lab.
Because of browser limitations, this page is a guide and does not run live sniffing.
